# «Трекер задач» для Android (и iPhone)

Это готовый проект. Приложение работает без интернета, задачи хранятся на телефоне, напоминания приходят
как обычные уведомления Android даже когда приложение закрыто. Готовый .apk весит около 5-8 МБ.

## Самый простой способ получить .apk (без Android Studio и без установки чего-либо)
1. Зарегистрируйтесь на https://github.com (бесплатно) и создайте новый репозиторий (кнопка «New»).
2. Распакуйте архив. В репозитории нажмите «Add file → Upload files» и перетащите внутрь все ФАЙЛЫ из корня папки (достаточно файлов: `index.html`, `package.json`, `capacitor.config.json`, `debug.keystore` и пять картинок `icon-*.png`, `splash*.png`). Папки `www` и `assets` загружать необязательно, сборка создаст их сама.
   Если папка `.github` не загрузилась (скрытые папки иногда пропускаются), нажмите «Add file → Create new file»,
   в имени файла напишите `.github/workflows/android.yml` и вставьте туда содержимое файла `github-workflow-android.yml`.
3. Откройте вкладку «Actions», выберите «Build Android APK» и нажмите «Run workflow». Сборка идёт 5-10 минут.
4. Когда появится зелёная галочка, откройте запуск и внизу, в блоке «Artifacts», скачайте `dela-android-apk`.
5. Внутри архива файл `app-debug.apk`. Отправьте его на телефон, откройте и разрешите установку из этого источника.
   Приложение появится на экране с иконкой. Таким же файлом можно поделиться с друзьями (см. ниже).

## Если уже установлен Android Studio
```
npm install
npx cap add android
```
В файле `android/app/src/main/AndroidManifest.xml` перед `</manifest>` добавьте:
```
<uses-permission android:name="android.permission.POST_NOTIFICATIONS"/>
<uses-permission android:name="android.permission.SCHEDULE_EXACT_ALARM"/>
```
Дальше `npm run assets`, `npx cap sync android`, `npx cap open android`, и Build → Build APK(s).

## Как делиться приложением с друзьями
- Внутри приложения: «Настройки» → «Поделиться». Откроется системное меню «Отправить» с текстом и ссылкой.
- Чтобы в сообщении была ссылка на скачивание, загрузите `app-debug.apk` в раздел Releases вашего репозитория на GitHub
  (кнопка «Create a new release») и впишите адрес файла в константу `SHARE_URL` в начале скрипта файла `www/index.html`.
- Для Google Play нужна подписанная сборка (AAB) и аккаунт разработчика (одноразовый платёж 25 $).

## Что уже подготовлено для телефона
- Нижняя панель вкладок, крупные кнопки, лёгкий режим без тяжёлых эффектов.
- Меню «⋯» у задач (редактировать, отложить, в группу, удалить).
- Напоминания по задачам и ежедневный вопрос «Как настроение?» как системные уведомления.
- Резервная копия: «Настройки» → «Резервная копия».

## iPhone
Нужен Mac с Xcode: `npx cap add ios`, `npm run assets`, `npx cap sync ios`, `npx cap open ios`. С бесплатным Apple ID
приложение работает 7 дней, для постоянной установки нужна программа Apple Developer (99 $ в год).

## Обновление приложения
Загрузите в репозиторий новый `index.html` (и при необходимости `debug.keystore`, `.github/workflows/android.yml`), заново запустите «Build Android APK»
и установите новый .apk поверх старого. Данные сохранятся, потому что файл `debug.keystore` делает подпись одинаковой.
Один раз при переходе со старой сборки на эту её нужно удалить: перед этим сделайте копию в «Настройки → Резервная копия → Скачать».
